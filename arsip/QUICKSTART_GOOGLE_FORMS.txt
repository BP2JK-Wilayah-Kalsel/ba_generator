2. ➕ Klik: "+ Blank" (form baru)

4. 📥 Pilih: "Import questions"

5. 📤 Upload: File "GOOGLE_FORMS_IMPORT.csv"

6. ✅ Klik: "Import questions"

7. 🎨 Edit judul form:
   Judul: "Evaluasi & Feedback Aplikasi BA Generator"
   
   Deskripsi:
   "Terima kasih telah menggunakan Aplikasi BA Generator. 
    Feedback Anda sangat berharga untuk pengembangan aplikasi ini. 
    Mohon luangkan waktu 5-10 menit untuk mengisi formulir evaluasi ini.
    
    Program Aktualisasi Latsar 2025
    Pengembang: Muhammad Rayhan Kurniawan, CPNS Kementerian Pekerjaan Umum"

8. ⚙️ Settings (ikon gear):
   ✓ Collect email addresses
   ✓ Limit to 1 response
   ✓ Edit after submit

9. 🎨 Theme (ikon palette):
   Warna: Biru

10. 🚀 Send (tombol Send):
    Copy link → Bagikan ke Pokja & Timlak!

TIPS ANALISIS HASIL:
============================================================================

Setelah responses masuk:

1. 📊 Lihat "Responses" tab
   - Summary: Chart otomatis
   - Individual: Per responden

2. 📥 Export ke Excel:
   - Klik ikon "More" (3 titik)
   - "Download responses (.csv)"
   - Buka di Excel untuk analisis detail

3. 📈 Buat laporan:
   - Average satisfaction score
   - Time savings calculation
   - Feature adoption rate
   - NPS (Net Promoter Score)

4. 💬 Compile testimoni:
   - Filter positive testimonials
   - Gunakan untuk laporan aktualisasi

============================================================================
CONTOH METRICS UNTUK LAPORAN:
============================================================================

1. User Satisfaction Score: 
   Average rating dari semua pertanyaan skala 1-5

2. Time Efficiency:
   Before: [rata-rata waktu manual]
   After: [rata-rata waktu dengan aplikasi]
   Savings: [selisih dalam jam/menit]

3. Feature Adoption:
   - BA Pokja: X% users
   - BA Timlak: Y% users  
   - SPSE Auto-fill: Z% users

4. Net Promoter Score (NPS):
   % users yang "pasti" atau "kemungkinan besar" recommend

5. Quality Improvement:
   % users yang menyatakan kualitas dokumen meningkat
