LANGKAH-LANGKAH:

1. Buka Google Forms: https://forms.google.com

2. Klik "+ Blank" untuk membuat form baru

3. Klik ikon "More" (3 titik vertikal) di pojok kanan atas

4. **PILIH "Import questions"**

5. Klik "Upload" atau "Select a file from your device"

6. Upload file: **GOOGLE_FORMS_IMPORT.csv**
   (File ini sudah ada di folder aplikasi BA Generator)

7. Klik "Import questions"

8. ✅ SELESAI! Semua 38 pertanyaan otomatis masuk ke form Anda!

9. Edit judul form:
   - Title: "Evaluasi & Feedback Aplikasi BA Generator"
   - Description: (copy dari bawah)

TIPS GOOGLE FORMS:
==========================================================================

1. SETTINGS yang direkomendasikan:
   ✓ Collect email addresses
   ✓ Limit to 1 response per user
   ✓ Edit after submit (optional)
   ✓ See summary charts and text responses

2. THEME:
   - Pilih warna tema: Biru (sesuai branding pemerintah)
   - Upload header image (optional): Logo Kementerian PU

3. SHARING:
   - Get link to share
   - Atau: Embed di website
   - Atau: Kirim via email langsung dari Google Forms

4. RESPONSES:
   - Lihat Summary untuk statistik otomatis
   - Export ke Excel untuk analisis lebih detail
   - Set up notification untuk setiap response baru

5. ANALYSIS OTOMATIS:
   Google Forms akan otomatis membuat:
   - Chart untuk multiple choice
   - Persentase untuk linear scale
   - Word cloud untuk paragraph answers (eksternal tools)
