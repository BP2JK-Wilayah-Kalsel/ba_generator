ANTIVIRUS & SECURITY
--------------------
⚠ Beberapa antivirus mungkin menandai file .exe sebagai suspicious
  (False positive - karena executable dibuat dengan PyInstaller)
  
Solusi:
- Add exception untuk BA Generator.exe di antivirus Anda
- Atau: Disable antivirus sementara saat pertama kali menjalankan
- File ini AMAN - dibuat dengan tools resmi Microsoft/Python

FIREWALL
--------
⚠ Windows Firewall mungkin menanyakan izin saat pertama kali
  
Solusi:
- Klik "Allow access" atau "Izinkan akses"
- Aplikasi hanya menggunakan localhost (tidak ada koneksi keluar
  kecuali untuk SPSE crawler)

============================================================================
TROUBLESHOOTING UMUM
============================================================================

MASALAH: "Windows protected your PC"
SOLUSI: Klik "More info" → "Run anyway"
        (File ini aman, hanya tidak ada digital signature)

MASALAH: Aplikasi tidak bisa dibuka
SOLUSI: 1. Pastikan Windows 10/11 (64-bit)
        2. Right-click → Properties → Unblock (jika ada)
        3. Extract ulang dari ZIP
        4. Disable antivirus sementara

MASALAH: Port 5000 already in use
SOLUSI: 1. Tutup aplikasi lain yang menggunakan port 5000
        2. Restart komputer
        3. Atau: Ganti port di source code (untuk developer)

MASALAH: Browser tidak terbuka otomatis
SOLUSI: Buka manual browser, ketik: http://127.0.0.1:5000

MASALAH: Error saat generate dokumen
SOLUSI: 1. Pastikan Microsoft Word terinstall
        2. Cek folder Master Template lengkap
        3. Pastikan tidak ada file Word yang terbuka
        4. Pastikan ada izin write di folder processed_results
